# MEDS

Projects, practice work, and assignments completed during my internship at MEDS Lab, UET Lahore (Summer Training Programme 2026).

## Structure

```
riscv-log-analyzer/                 # Module 1 — shell tool for RISC-V sim log reports
riscv-decoder/                      # Module 2 — C tool decoding RV32I machine code
riscv-assembly-challenge/           # Module 3 — array ops, recursion, instruction encoding
radix2-booth-multiplier/            # Module 4 — sequential 8-bit signed Booth multiplier (SystemVerilog)

MEDS-Training/
├── door_sensor_logger/             # C evaluation assignment
├── module0-onur-lecture-notes/     # notes on Prof. Onur Mutlu's DDCA lectures (ETH Zürich)
├── module1-practice/               # linux, shell scripting, makefiles
├── module2-practice/               # C: RISC-V instruction packing/decoding, memory
├── module3-practice/               # RISC-V assembly exercises
└── module4-tasks/                  # SystemVerilog digital design (t01–t18)
```

## Modules

| Module | Topic | Deliverable |
|---|---|---|
| 1 | Linux & Shell Fundamentals | `riscv-log-analyzer` |
| 2 | C, Memory, RISC-V Instruction Encoding | `riscv-decoder` |
| 3 | RISC-V ISA & Assembly | `riscv-assembly-challenge` |
| 4 | SystemVerilog Project  | `radix2-booth-multiplier` |

Each project folder has its own README with build and run instructions.
